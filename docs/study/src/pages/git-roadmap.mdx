## 🔮 Future Product Roadmap & Architectural Horizons

### 📡 1. v1.4.0 — Real-Time Wearable Ingestion & FHIR R5 Subscriptions
- **Web Bluetooth & Health Connect Sync**: Direct real-time ingestion of optical pulse wave (PPG), heart rate variability (HRV), and continuous SpO₂ streams into `PatientStateService`.
- **FHIR R5 `SubscriptionTopic` Streaming**: Server-sent event (SSE) and WebSocket pub/sub model broadcasting real-time patient status changes to connected clinical monitoring stations.

### 🧠 2. v1.5.0 — On-Device WebGPU & Gemini Nano Local Inference
- **Zero-Latency Offline LLM Fallback**: Full local execution via Chrome `window.ai` (Gemini Nano) and WebLLM for disaster recovery, rural clinics, and extreme privacy-isolated consults.
- **WebGPU Acceleration**: Offloading 3D spatial particle systems and local tensor computations directly to client GPUs (NVIDIA, AMD, Apple Silicon).

### 🌐 3. v2.0.0 — Federated WebMCP Multi-Agent Panel Consensus
- **Model Context Protocol (MCP) Tool Mesh**: Inter-agent multi-specialty panels where specialized agents (Cardiologist, Pharmacologist, TCM Master, Ayurvedic Vaidya) deliberate concurrently.
- **Post-Quantum Cryptography (PQC)**: Kyber/Dilithium AEAD envelopment for end-to-end self-sovereign patient records.

## 🔄 Software Development Lifecycle (SDLC) & DevSecOps

Pocket Gull enforces a **Shift-Left DevSecOps SDLC**:

1. **Shift-Left Pre-Commit Validation (`pre-commit-check.cjs`)**:
   - TypeScript strict type checking (`tsc --noEmit`).
   - Vitest automated unit & safety red-teaming execution (`tests/safety.spec.ts`).
   - Markdown image reference validation.
   - Shannon Entropy secret scanner.
   - **Sentinel Security Guard** network egress domain whitelist auditing (`generativelanguage.googleapis.com`, `fhir.org`, `cloudrun.app`).

2. **Automated CI/CD Security Pipeline (`.github/workflows/deploy.yml`)**:
   - Step-Security `harden-runner v2.16.0` with `disable-sudo: true`.
   - CodeQL static analysis for Javascript/Typescript and Python.
   - OpenSSF Scorecard automated security posture scoring.
   - Automated deployment to Google Cloud Run with Google Cloud Secret Manager integration.
